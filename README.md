# One Line, One Laugh: Roast Your Fridge

A single original line roasting our own fridge — its ice maker, to be exact. It growls, it rattles, it makes a whole production of it, and then it drops two cubes like it's doing us a favour. The laziest employee in the house.

`main.py` (pure Python stdlib) writes the one line to `/output/entry.txt`, validated to the gate: 1–200 characters, not only whitespace.
